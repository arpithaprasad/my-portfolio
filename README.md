# 6 months

A handmade single-page anniversary scrapbook (Next.js 16, React 19, Tailwind v4).

All placeholder copy, dates, memories, stats, locations, and the boyfriend name live in `app/data/anniversary.ts`. Polaroid photos are labeled `PHOTO` blocks on purpose — swap those when real pictures are ready.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```
